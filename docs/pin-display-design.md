# 超出屏幕的贴图显示与缩放

iSnip v1.0.8 恢复一张 1,622 × 30,000 像素的图后，实体显示器上只短暂出现了贴图。同一个窗口仍在，macOS 的 `WindowServer` 反复报告无法分配绘图空间。缩小这个窗口后，报错停止，图也持续显示。旧记录把窗口恢复到 12,860 点高，在这台 2 倍显示的 Mac 上对应 25,720 像素高。

## 打开和恢复

1. 先选贴图实际要出现的屏幕。新贴按本次的放置位置选屏。恢复时选和历史窗口位置重叠最多的当前屏幕。旧位置找不到对应屏幕时，用鼠标所在的屏幕。
2. 比较贴图原始大小与目标屏幕的可用宽高，尺寸统一用点。屏幕可用范围扣除菜单栏和程序坞。宽和高都小于或等于可用尺寸时，按普通贴图打开或恢复。
3. 原始宽度或高度有一边超出时，新贴和每次从历史恢复都先进入「适合窗口」。按宽高所允许的较小倍率等比缩放，让整张图一次看全。

这张 2 倍长图的原始大小为 811 × 15,000 点。目标屏幕可用约 1,920 × 963 点，所以需按高度适配，全图倍率约为 6.4%。外框被拖到屏幕边缘时按位置处理，尺寸判定仍以贴图原始大小为准。

## 缩放和拖动

- 滚轮以鼠标指向的图像位置为中心缩放。100% 代表贴图原始大小，手动的倍率范围为 20%～400%。滚轮经过 100% 时在原始大小停一格。
- 全图倍率低于 20% 时，从全图放大的第一格进入 20%。从 20% 再往小滚一格回到「适合窗口」。全图倍率在手动范围内时，可以用正常缩放看到全图，滚轮缩小不会把图片放大。
- 随着图片放大，贴图外框可以变宽、变高。到达当前屏幕可用宽高后，继续放大图片，外框的对应边保持在屏幕尺寸上限。普通贴图放大到超出屏幕时也应用这个窗口上限。
- 全图可见时，拖动图片会移动整个贴图窗口。长图和图片高度超出外框的贴图也用这个拖动方式，并收起顶部的灰色移动把手。仅横向超出的宽图可以左右拖图浏览，拖顶部把手可以移动整个窗口。移动到其他屏幕后，按落位的屏幕重新计算可用范围。
- 复制和保存使用完整贴图内容。缩放和窗内浏览只改变屏幕上看到的范围和比例。

## 窗内浏览和操作提示

图片显示出来的高度超过贴图窗口时，按住 `⇧ Shift` 滚动可上下浏览。滚到顶部或底部就停在边界，窗口位置和缩放比例保持在浏览开始时的状态。直接滚轮用于缩放。组合中含 `⌘ Command` 或 `⌃ Control` 时，滚轮优先调整透明度。

普通滚轮放大图片后，如果图片显示的高度超过窗口可见高度，就在该贴图所在屏幕顶部显示两行提示。

> **上下浏览长图**
>
> 按住 ⇧ Shift 并滚动滚轮

提示最多显示 15 秒。在同一张贴图上使用 `Shift + 滚轮` 实际上下移动一次图片，就提前收起提示。滚轮在图首或图尾被挡住时，提示继续等待。

每次打开一张贴图最多显示一次，触发动作是放大。屏幕顶部已有其他提示时，先让当前提示显示完。这次长图指引留到当前贴图下一次符合条件的放大操作。只有指引实际显示才计入次数。已经显示过的贴图缩回全图再放大、换屏或从标注返回时，沿用本次打开的计数。关闭后重新贴出或恢复时，按新一次打开计算。

## 实现要点

- 在创建 `NSPanel` 和绘制视图之前先确定安全的外框。窗口第一次分配绘图资源时就使用这个尺寸。新贴、旧历史恢复、滚轮缩放、重置和换屏都使用同一套尺寸规则。
- 由 `PinWindowController` 管理原始大小、当前倍率和可见的原图区域。绘制只覆盖有上限的视图，按缩放比例和窗内浏览的位置从原图取对应范围。显示区域一直受贴图外框限制。
- 读取现有历史的原图和原始大小，用旧位置选屏。原始大小超屏的记录每次重算「适合窗口」，包括过去保存了过大外框的记录。按普通贴图恢复时，使用历史的显示状态并检查实际窗口尺寸。
- 保留完整图像给复制、保存、OCR 和历史。贴图标注要以窗口上显示的原图坐标为准，避免把外框误当成整张图的显示尺寸。
- 完整解码这张长图本身约占 186 MiB。关闭后等历史写入完成再检查内存，确认反复恢复和关闭不会持续累积。

决定背景见[限制贴图窗口的绘制尺寸](adr/0003-bound-pin-window-size.md)。

## 验收用例

| 场景 | 通过条件 |
| --- | --- |
| 旧安装留下的 1,622 × 30,000 像素历史 | 安装验证版后按 F3，从首帧起在实体显示器上看到完整长图，停留至少 5 秒仍然显示。 |
| 从剪贴板新贴同一张长图和一张超宽图 | 两张图分别按限制更紧的一边等比打开，开头到末尾都可见。 |
| 从约 6.4% 的全图放大 | 第一格到 20%，经过 100% 时停一格，继续可到 400%。外框可以跟随放大到屏幕可用大小，鼠标指向的图像区域保持在附近。 |
| 放大后移动长图贴图 | 拖动长图或高度超出窗口的图片，整个窗口跟随鼠标移动，窗内可见区域和倍率保持，顶部灰色移动把手收起。 |
| 缩小和再次打开 | 全图倍率低于 20% 的图片从 20% 再缩一格回到全图。放大到中段后关闭，再按 F3 仍先看到全图。全图倍率高于 20% 的图片可缩到 20%，继续缩小不会跳回更大的倍率。 |
| 完整复制和保存 | 放大后用 `Shift + 滚轮` 浏览到图中段，复制和保存的结果包含整张图，像素尺寸和正文完整。 |
| 普通图与边界尺寸 | 原始宽高等于可用宽高也算放得下。验证普通图拖动、恢复、100% 停靠、标注和 OCR，并确认它放大超屏时窗口有尺寸上限。 |
| 不同缩放的显示器 | 将放大的贴图移到另一块更小或显示比例不同的屏幕。移除原屏幕后，再恢复旧历史，按新选中的屏幕算尺寸，贴图保持可见。 |
| 连续恢复与关闭长图 | 实体显示器上的贴图在打开期间稳定可见。关闭并等历史写盘后，重复操作的内存占用不会持续累积。 |
| 滚轮缩放与上下浏览 | 将长图放大到能上下滚动。直接滚轮仍调整倍率，`Shift + 滚轮` 连续查看图片后续内容，窗口位置和倍率保持。到图首或图尾时停在边界。 |
| 提示出现的条件 | 普通滚轮放大图片，且放大后图片比窗口高时，在贴图所在屏幕顶部显示两行提示。全图可见和仅横向超出时，`Shift + 滚轮` 停在当前画面。 |
| 提示收起 | 在提示显示期间用 `Shift + 滚轮` 实际滚动同一张图，提示立即收起。只在边界空滚时，提示继续等待。15 秒内未发生实际滚动，提示在到期时收起。 |
| 提示次数 | 放大后提示过，再缩回全图后重新放大时，沿用本次打开的计数。打开第二张图独立计数。关闭后用 `F3` 恢复同一张图，下一次放大符合条件时可以提示一次。 |
| 操作提示让位 | 顶部正显示 OCR 等状态时放大长图，状态提示继续显示。状态消失后，下一次符合条件的放大操作可以补上提示。 |
