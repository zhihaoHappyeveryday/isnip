# 长截图确认拼接后再继续滚动

长截图拼接需要相邻画面的重叠。旧流程优先让滚动继续，遇到丢帧时可能跨过整段内容。自动滚动每一步都等抓屏和拼接确认，失败时先补抓，再有限回滚。这样多花的时间集中在失败步骤，已获得的长图可以保留，避免把漏接的结果当作成功输出。

改用实时首屏前，先验证能与框选时的画面接上。切页或提前滚动可能产生内容错误但能继续拼接的长图，所以只有在还未成功拼入新内容且用户确认了当前预览时，才允许从新起点开始。自动回滚只在发出向下滚轮后用于尝试接回，回滚次数与滚轮发送量都有上限。

输出要求至少已拼入一段内容，并确认当前位置接得上。高度上限是一次明确的停止，允许输出已经连续拼好的部分。具体交互和验收见 [长截图拼接中断修复设计](../longshot-recovery.md)。

后续设计只在能够可靠回到最后接上的位置时自动回退一次，回退后确认接缝再继续。见 [用同一滚动区域的正文确认长截图接缝](0004-verify-longshot-selection-seams.md)。
