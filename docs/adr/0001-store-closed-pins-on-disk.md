# 将已关闭贴图存入会话缓存

已关闭贴图按用户配置的张数保留，默认 20 张，最多 50 张。之前的位图内存预算只能保留约 6 张 4K 截图。把无损图像和贴图原文写入磁盘后，历史只需在内存里保留顺序和显示状态，空闲内存随历史增长的幅度也会下降。

关闭时保存当前图像和显示状态，并释放窗口。后台一次写一张。待写图仍可马上恢复，已存图在请求恢复时单独读取。达到张数上限时从最早关闭的开始淘汰。写入失败时照常关闭并提示。设为 0 时清空历史。

默认使用截图保存目录下的 `iSnip Pin History` 子目录。可自选父目录并恢复默认。改路径后新关闭的图使用新位置，已有记录继续使用原位置。每次运行只读取本次创建的历史。会话目录随退出清理，异常退出时由下次启动清理。
