# 用同一滚动区域的正文确认长截图接缝

小选区容易被固定栏占满，框内可能缺少足以判断位移的正文。长截图用同一滚动区域内更大的可见画面估算位移，再检查原选区是否仍有重叠，接上后才写入新增内容。这样可以用框外正文找到位置，同时确保成图只包含用户选中的连续内容。

原地补抓后仍无法确认接缝时，有可靠的恢复位置才自动退回一次，接上后减速继续。回退位置不确定或尝试失败时，停住并保留进度，让用户手动接回。这样在已知位置时可以自动截到底，也避免在同一处反复滚动。此决定调整 [ADR 0003](0003-verify-longshot-before-advancing.md) 中的自动回滚规则。
