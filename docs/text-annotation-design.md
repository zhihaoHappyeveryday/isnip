# 文字标注原地输入

选中文字工具后，在截图上点一下就从那个位置开始写。输入、确认和导出的文字使用同一个起点和排版，打字时可以看见文字下面的截图。

## 放置和输入

- 文字工具启用时，鼠标在可以放置文字的区域显示 macOS 的细 I 形文字指针。点击空白处开始编辑，闪烁的插入线从点击处开始。文字使用工具栏中选定的字体、字号和颜色。
- 输入时使用透明编辑区，文字和插入线直接显示在截图上，编辑区域随文字增长。靠近截图边缘时也使用原来的点击位置，可见范围由截图边界决定。
- 新文字从起点向右排，到标注区域的右边缘自动换行。回车可以主动换行。输入时的换行、行距和文字位置延续到确认后的画布、复制和保存。
- 编辑中点下一处空白，确认当前文字并在新的位置开始输入。点工具栏上的复制、保存等按钮时，先确认当前文字，再执行按钮操作。

## 选中、移动和修改

- 单击已有文字显示细边框，可以拖边框移动整段文字，拖四角调整大小。移动保留已经排好的行。文字移过截图边缘时，超出的部分按边界裁切，移回后可以继续看到全部内容。
- 双击已有文字，从原位置和原排版开始修改。编辑时画布显示当前编辑的文字。修改内容或样式时，按原来的换行宽度排字。
- 按 `Esc` 取消当前文字编辑，仍留在截图标注界面。新建草稿随之丢弃，已有标注恢复原文和位置。输入法正在选词时，先由系统处理回车、`Esc` 和候选窗点击。
- 新建时空内容确认后直接结束编辑。把已有文字删空再确认时移除该标注，可以通过标注的撤销操作找回。

## 布局与输出

普通截图、长截图成图后标注和贴图标注共用这套交互。截图直接用选区确定文字起点。放大的贴图用当前标注区域确定新文字的换行宽度，再将文字的位置和排版换算回完整原图，预览显示窗口里可见的部分。

保留原生文字编辑器处理输入法、插入线、文字选区和编辑快捷键。文字起点定义为第一行排版的左上角。编辑器和画布使用一致的起点、换行宽度和行距。选中边框根据实际文字范围绘制。重新编辑时，由编辑器负责显示这条文字，当前标注仍保留用于取消和撤销。

确认、复制和保存使用同样的文字排版。插入线、选中边框和输入法候选窗属于编辑界面。

## 验收用例

| 场景 | 通过条件 |
| --- | --- |
| 在截图白底处点一下写红字 | 可标注区域显示 I 形指针。插入线从点击处开始，打字时看到红字和下面的原图。确认后的字与输入时对齐。 |
| 长句碰到右边缘 | 文字自动换行。回车可增加一行。输入、确认和导出时换行、行距和起点一致。 |
| 点击截图最右或最下方 | 即使首字或首行只能部分容纳，起点仍保留在点击处，显示和输出按截图边界裁切。 |
| 连续点击两个空白位置 | 第二次点击确认前一条，并在该位置打开下一条文字输入。 |
| 移动及重新修改多行标注 | 单击后出现细边框。拖动整段时行数和行间布局保持。超出边缘的部分移回后可见。双击进入编辑时看到的是当前编辑的文字。 |
| 编辑时按 Esc 或清空后确认 | Esc 取消当前草稿或恢复原文，标注界面仍打开。已有文字清空并确认后移除，可以撤销找回。 |
| 中文拼音选词 | 系统候选窗可见。按回车确认候选后再按回车换行，选词时 Esc 先按输入法规则处理。 |
| 普通截图、长截图和缩放贴图 | 三个入口的指针和输入规则一致。复制或保存后，在原图所对应的位置看到同样排版的文字。 |
