# 文字标注原地输入

## 问题

在 `1.0.9-bate-2` 中，用白色 I 形指针点在一条横线上后，蓝色插入线从横线向下画，输入的文字也跟着偏低。用苹方在同一位置实测，16 pt 时蓝线中点低约 11 点，32 pt 时低约 22 点。点击点当前用作第一行排版的左上角，所以偏移随行高增加。

## 方案

选中文字工具，在截图上点一下就从鼠标瞄准的高度向右写。输入、确认和导出共用同一个文字起点和排版。

### 放置和输入

- 可放置文字的区域显示 macOS 的细 I 形文字指针。点击空白处时，白色指针瞄准的位置对齐首行蓝色插入线的中点。文字使用工具栏选定的字体、字号和颜色。
- 输入时使用透明编辑区，文字和插入线直接显示在截图上，编辑区域随文字增长。靠近选区上沿仍按点击点放置，超出选区的部分按边界裁切。
- 新文字从起点向右排，到标注区域的右边缘自动换行。回车可以主动换行。输入时的换行、行距和文字位置延续到确认后的画布、复制和保存。
- 编辑中点下一处空白，确认当前文字并在新的位置开始输入。点工具栏上的复制、保存等按钮时，先确认当前文字，再执行按钮操作。

### 选中、移动和修改

- 单击已有文字显示细边框，可以拖边框移动整段文字，拖四角调整大小。移动保留已经排好的行。文字移过截图边缘时，超出的部分按边界裁切，移回后可以继续看到全部内容。
- 双击已有文字，从原位置和原排版开始修改。编辑时画布显示当前编辑的文字。修改内容或样式时，按原来的换行宽度排字。
- 给已经确认的文字用工具栏改字号时，以文字框左上角为支点。
- 按 `Esc` 取消当前文字编辑，仍留在截图标注界面。新建草稿随之丢弃，已有标注恢复原文和位置。输入法正在选词时，先由系统处理回车、`Esc` 和候选窗点击。
- 新建时空内容确认后直接结束编辑。把已有文字删空再确认时移除该标注，可以通过标注的撤销操作找回。

## 用户故事

1. 作为截图标注用户，我希望点在一条横线上就能从同一高度向右写，便于把文字放到想标注的内容旁边。
2. 作为会切换字号的用户，我希望用 16 pt 和 32 pt 在同一高度点击时，插入线中点对准同一条横线。
3. 作为使用中文输入法的用户，我希望能在原地选词，确认候选后直接看到文字。
4. 作为在选区边缘添加标注的用户，我希望首行按点击点放置，超出画面时由边界裁切。
5. 作为连续添加标注的用户，我希望点下一处空白就能确认上一条并在新位置开始输入。
6. 作为复制或保存标注的用户，我希望得到与编辑时同位置、同换行的文字。
7. 作为回头改错字的用户，我希望双击后能看到原来的文字位置，改完后继续留在原处。
8. 作为调整已写好文字字号的用户，我希望文字框的左上角固定，方便和其他标注对齐。
9. 作为给长截图加文字的用户，我希望导出完整长图时，标注落在预览时选定的地方。
10. 作为给缩放贴图加文字的用户，我希望按当前看到的画面放置文字，并能在完整原图上找到这处标注。

## 实现决定

1. 在共用的标注画布里，根据当前字体和字号取得原生编辑器空白首行的插入线位置。新建时横坐标取点击点的横坐标，纵坐标从点击高度向上减去首行插入线中点到排版顶部的距离。换算使用画布的逻辑坐标。
2. 文字起点是换算后第一行排版的左上角。新建时确定一次，原生编辑器和标注对象共用。确认时写入标注对象，画布和导出都从该位置排字。双击修改时直接读取已有文字起点。
3. 普通截图、长截图成图后标注和贴图标注共用这套放置规则。普通截图按选区裁切。缩放贴图按窗口可见范围显示，导出时将排版映射回完整原图，并按原图边界裁切。
4. 原生文字编辑器处理输入法、插入线、文本选区和键盘操作。编辑器和画布使用一致的起点、换行宽度和行距。选中边框根据实际文字范围绘制。再次编辑时，原标注仍用于取消和撤销。
5. 插入线、选中边框和输入法候选窗属于编辑界面。复制和保存使用确认后的文字排版。

## 测试决定

以标注画布的实际交互作为主要测试入口。沿用现有的文字标注测试来核对输入、确认和导出的可见结果，断言改为核对首行插入线的中点与点击高度。交互验收使用带水平参考线的画面，操作待验收版本的截图界面，从鼠标框选、点击文字工具、落点到打字、确认逐步观察。允许一个显示像素的取整差异。

## 验收用例

| 场景 | 通过条件 |
| --- | --- |
| 用真实鼠标在同一条横线上分别写 16 pt 和 32 pt | 点击前白色 I 形指针的中间对准参考线。点下后蓝色插入线的中点落在参考线上。分别输入中文和英文，核对确认前后与导出中的文字位置和换行。 |
| 长句碰到右边缘 | 文字自动换行。回车可增加一行。输入、确认和导出时换行、行距和起点一致。 |
| 点击靠近选区上沿、右沿和下沿的位置 | 首行按点击点放置。靠上时即使首行只能显示一部分，仍以点击高度为准。文字显示和输出遵循对应的画面边界。 |
| 连续点击两个空白位置 | 第二次点击确认前一条，并在该位置打开下一条文字输入。 |
| 移动及重新修改多行标注 | 单击后出现细边框。拖动整段时行数和行间布局保持。超出边缘的部分移回后可见。双击进入编辑时看到的是当前编辑的文字。 |
| 确认后用工具栏把 16 pt 改为 32 pt，再双击修改 | 调字号时文字框的左上角保持在原位。双击时沿用当前文字的位置和换行宽度。 |
| 编辑时按 Esc 或清空后确认 | Esc 取消当前草稿或恢复原文，标注界面仍打开。已有文字清空并确认后移除，可以撤销找回。 |
| 中文拼音选词 | 系统候选窗可见。按回车确认候选后再按回车换行，选词时 Esc 先按输入法规则处理。 |
| 普通截图、长截图和缩放贴图 | 三个入口的指针和输入规则一致。复制或保存后，在原图所对应的位置看到同样排版的文字。 |

## 修复范围

本次修复集中在新建文字的定位和对应验收。连续放置、拖动缩放、编辑取消、输入法及完整导出用于回归验证。

## 补充说明

上一个版本的测试把编辑框左上角与点击点重合作为通过条件，也验证了编辑和导出一致。复现时以屏幕上的点击点和蓝线中点为测量对象，才能捕捉这次用户看到的偏移。
