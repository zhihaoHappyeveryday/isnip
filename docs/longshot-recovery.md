# 长截图拼接中断修复设计

## 问题

长截图靠相邻两次截图里的共同内容判断接缝。滚动后如果没抓到画面，或者两张图已经没有足够的重叠，就无法知道中间漏了什么。v1.0.3 遇到抓屏没有结果时会进入下一轮滚动。对不上时会原地补抓一次，再减小后续步长。页面可能继续往下走，预览却停在上一段。点击完成时，最后一次抓屏或拼接失败也会输出已有图像，可能只有首屏。

v1.0.3 在 Chrome 彩色测试页上滚动了 1,800 CSS px，暂停后得到的图是 1569 × 2590，完整的测试行到第 025 行。当时页面已滚到约第 035 行。这个实测确认了少拼后半段，首次丢帧或对不上的原因仍未定位。用现有拼接代码回放高度为 120 px 的画面时，按 0、70、140 px 采样可以拼出 260 px。跳过 70 px 处的画面后，首尾接不上，结果停在 120 px。

## 滚动与恢复

1. 自动滚动一步后，等页面绘制并抓屏。确认新画面有足够重叠、把新内容拼进去后，再继续向下滚。步长以实际可滚动区域为准，已识别的固定页眉、页脚要扣除。小选区也要保留重叠。
2. 暂时抓不到画面、画面看起来没动，或新画面对不上时，先在当前位置限次补抓。画面相同只能说明没有识别到新内容。能够确认仍在已拼位置时可停滚，工具条用「未检测到新内容」说明结果。
3. 能抓到画面但补抓后仍对不上时，向上小步回滚并逐次检查是否能接上。使用最后一次确认的画面做参考，首屏可作初始参考。回滚途中只检查接缝，已截过的内容保持原样。接回后用更小的步长继续，只拼进超出已有图像的内容。回滚后仍一直停留在同一段时，下一次失败就交给用户手动接回。
4. 一轮有上限的回滚仍接不上，或持续拿不到画面时，停滚并在工具条提示「拼接中断，请往回滚一点」。保留预览和工具条，手动滚回重叠处后即可继续。恢复期间按空格会立即停止发送滚动事件，并检查当前位置。已经发出的滚动可能需要等页面绘制完再抓屏。
5. 自动翻页开始或继续时，沿用现有的光标判定。光标在目标区域内的适合位置时留在原位，需要时移到选区中间附近，帮助滚轮事件落在目标区域。向上回滚使用同一类滚轮事件。 [现有光标与滚轮处理](../Sources/AirSnipApp/SystemServices.swift#L368)

## 暂停与输出

- 按空格暂停后，等刚发出的滚动稳定下来，再检查当前位置。能接上的新内容加进预览，工具条继续保留。
- 自动滚动时点复制、保存、另存为、标注或 OCR，先停滚并补抓最后一屏。已拼入至少一段内容且当前位置已确认接上时，才结束会话并输出。仍接不上时保留工具条和预览，可手动接回后再试。只有首屏时提示「尚未拼成长截图」。
- 确认下一段能接上，但整段加进去会超过高度上限时，停止滚动，在工具条的「宽 × 高」旁显示「已达上限」。已拼成的长图可直接输出，超限段留在图外。输出仍要求已经拼入至少一段内容。如果第一段已经超限，可手动往回一点，再试较短的一段。

## 实现位置

`LongshotSessionController` 负责滚动、抓屏、恢复和工具条状态。复用现有抓屏循环和共用的输出入口，按顺序处理发送滚动、等待画面、拼接三个阶段。失败时先解决当前滚动，暂停或输出请求切换后，较早的抓屏结果只能用于当前仍有效的检查。所有输出操作共用一次检查，通过后再关闭工具条。 [会话控制器](../Sources/AirSnipApp/LongshotOverlayController.swift#L32) · [共用输出入口](../Sources/AirSnipApp/LongshotOverlayController.swift#L665)

`LongshotCanvas` 负责验证重叠和写入图像。把回滚时的重叠检查做成只读，复用已有行匹配。只有验证通过且能接入的新像素才进入画布。匹配失败或超限时，已拼像素和最近一次可接续的参考一起保留。正常拼接每步取一帧。能同时用不同的滚动距离解释画面时，等新画面提供足够依据再接入。 [拼接入口](../Sources/AirSnipCore/LongshotEngine.swift#L1193) · [画布写入](../Sources/AirSnipCore/LongshotEngine.swift#L1330)

## 验收

| 场景 | 通过标准 |
| --- | --- |
| Chrome 彩色编号测试页 | 滚动后预览高度持续更新。按空格后，能接上的末屏进入结果。导出的行号连续，无漏行或重复。 |
| 第一次抓屏为空或画面仍在重绘 | 在当前位置补抓，接上后才发下一次正常的向下滚动。 |
| 一步滚得太远 | 有限回滚到可接的位置，再用更小的步长继续。画布中的已截内容不重复。 |
| 回滚仍无法接上 | 停滚，工具条提示拼接中断。手动滚回重叠处后，可接回并继续这一轮。 |
| 正在滚动或回滚时按空格 | 停止发送滚动事件，检查当前位置，保留控制条与已拼图像。 |
| 正在滚动时点任一输出操作 | 先停滚并补抓。接上后才输出，否则保持这一轮并提示。 |
| 只有首屏，或仍有未解决的拼接中断 | 复制、保存、另存为、标注和 OCR 一致受限。 |
| 下一段能接上但超过高度上限 | 显示「已达上限」，现有长图的预览与导出一致，画布没有加入超限段。 |
| 小选区、固定页眉和相似内容 | 步长留出可用重叠。画面难以区分时停滚检查，提示反映实际判定。 |
| 从选区外启动或继续 | 光标和滚轮事件沿用现有定位方式，目标区域继续可滚动。 |
