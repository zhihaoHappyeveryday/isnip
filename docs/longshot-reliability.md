# 长截图起步与续接设计

用户框选后点一次「自动翻页」，iSnip 自动截到所选滚动区域的末尾，停下来显示完整预览。试滚、补抓、减速和能够确认的续接由 iSnip 完成。用户在完成后选择复制或保存。成图使用原选区内连续出现的内容。

五组 macOS 真机样本里，v1.0.6 有一组能一次启动完整出图，组合原型五组都完成。中途跳过 34 像素时，原型保留已拼进度，三次尝试继续都停在原处，手动接回后完整出图。实验已知滚动区域的边界，正式验收还需要覆盖实际应用的滚动区域识别。

## 框选和起步

1. 原选区决定最后的成图范围。用当前能确认的窗口、页面和滚动区域信息识别目标，同一窗口换页时也要核对画面。框住多个滚动区域且目标不明确时，请用户把鼠标指向要截的正文，等能确认目标后再试滚。
2. 确认目标和位置相同后，用实时画面刷新首屏。页面只是重绘时仍可以从原位置直接开始。框选后页面已经移动并且还能接上时，保留框选时的首屏，接上新增内容后继续。
3. 画面暂时取不到就原地限次补抓。目标或起点仍无法确认时，停下并保留选区。若当前画面可作为新起点，显示预览，并在尚未拼入第一段时把控制条的「自动翻页」暂时改成「从这里开始」。用户确认这张预览后，才从当前画面重开。预览所指的目标或位置变了时，更新预览并等待新的确认。
4. 用户启动或恢复自动滚动时，鼠标已在要滚的正文内就留在原位。鼠标还在工具条或目标外，且已确认正文位置时，可以把它定位到正文内一次。之后每步只发送滚轮事件。

已开启自动翻页的入口和手动按「自动翻页」使用同样的起点确认与试滚流程。

## 小步滚动和验证接缝

- 在同一个滚动区域内取更多可见正文作为对齐参考。框的上下或左右有随同一正文移动的内容时，可以辅助匹配。确认不了框外边界时，先只用原选区小步试滚一次。确认不了应该滚哪个区域时，先请用户指明目标。
- 第一步按原选区中实际可滚动的正文高度留出足够重叠。固定栏占去的高度不计入正文。接上第一段后，按观测到的位移调整后续步长。原选区本身缺少足够正文时，提示扩大选区。
- 先判断画面移动了多少，再按该位移检查原选区的重叠部分。位置不唯一、原选区缺了一段或接缝仍不可信时，保留上一次确认的画面。比如原框内正文只有 24 像素，实际滚了 30 像素，即使能算出准确位移，也要先接回缺口才能继续向下。
- 暂时没有可用画面、仍在渲染或接不上时，先原地限次补抓。每一段得到确认后才继续下一步。抓屏晚到时，只给当前有效的滚动或输出操作使用。

## 自动续接

1. 发现失配后，先停发向下滚轮，在原地补抓。补抓恢复后，减小步长并自动继续。
2. 补抓仍接不上时，如果能确认仍是原滚动区域，并且有可靠方式回到最后接上的位置，允许自动回退一次。重新抓图确认已经接回后，减小步长继续滚。滚轮发送量可以用来控制步长，回退位置需要有可核对的依据。
3. 回退位置无法确认、回退失败，或接回后下一小步又失配时，暂停并保留进度。只有再次拼入新增内容，才可以对下一处中断尝试自动回退。失配位置收到重复的「自动翻页」操作时，只核对当前画面。

## 停止、手动接回和输出

| 情况 | 用户看到的行为 |
| --- | --- |
| 已经到所选滚动区域末尾，末屏已接上 | 自动停止并显示完整预览，可以复制或保存。 |
| 尚未拼入第一段，自动续接后仍接不上 | 保留原选区。可手动滚回保住开头，或确认当前预览后点「从这里开始」。可滚动正文太少时提示扩大选区。 |
| 已拼入内容，自动续接后仍接不上 | 停在当前位置并保留预览，提示手动慢滚到有重叠的位置。 |
| 手动滚回有重叠的位置 | 更新预览，只加入可确认的新增内容。可以继续手动滚动，需要自动滚动时再点「自动翻页」。 |
| 补抓后没看到正文移动，且无法确认已到末尾 | 暂停并显示「未检测到新内容」。如果还没拼入第一段，保留首屏供用户调整或继续。 |
| 点击复制、保存、另存为、标注或 OCR | 暂停发送滚轮，等刚发出的动作稳定，再检查末屏。已有连续拼接内容且末屏已确认时可以输出。仍失配时留在预览，接回后才输出。 |
| 已接上的下一段会超过高度上限 | 提示「已达上限」，允许输出已确认的长图。至少已拼入一段才有长图可输出。 |

## 实现边界

使用 ScreenCaptureKit 取得实时画面，并用现有匹配器计算对齐参考画面的移动量。可靠的实际位移可以辅助验证，滚轮发送量仅用于控制步长。滚动区域边界只有在能从窗口与滚动区域信息可靠确认时才用于扩展取样。原框接缝复核独立判断实际出图范围是否仍连续，画布只写入确认通过的新增行。

真机抓到的同一内容可能存在轻微色差。原型用独立记录的真实位移和完整参考图检验接缝。正式实现需要用不同应用、显示比例和动态内容标定接缝判断。所有图像判断都要能区分小量渲染差异、错误位移和真实缺口。

会话控制器负责确认目标、获取画面、安排滚动、自动续接、暂停和输出。拼接负责估算位移、验证接缝和更新已确认的长图。暂停或结束后到达的旧结果丢弃。[会话控制器](../Sources/AirSnipApp/LongshotOverlayController.swift) · [拼接引擎](../Sources/AirSnipCore/LongshotEngine.swift)

## 验收

| 场景 | 通过标准 |
| --- | --- |
| Chrome、Safari 与原生应用里的普通滚动内容 | 一次启动后自动截到所选滚动区域末尾，停在完整预览。逐行对照参考图，顺序连续，固定栏只出现一次。记录首次拼接和整次截图的耗时，与 v1.0.6 同场景对照。 |
| 小框带固定栏、框内重复或稀疏正文 | 有足够同一滚动区域的可见正文时能对齐，成图仍用原框，避免缺行和重行。 |
| 有明确滚动目标，但框外边界看不准 | 只用原框小步尝试，接上继续，失配则在原地暂停。 |
| 同一窗口里有多个滚动区域，目标不明确 | 等用户指向要截的正文，确认目标前页面保持原位。 |
| 框选后重绘、已经滚动或切页 | 同一位置重绘能起步。有重叠的移动保住原开头。切换目标时先确认，已有进度时只能接回原画面。 |
| 启动或滚动后短暂取不到图 | 在同一位置补抓，能接上后才继续。到达重试预算仍取不到则停。 |
| 画面没动，或更大的正文仍然无法辨认位移 | 暂停并给出原因。相同画面无法说明已经滚到末尾。 |
| 选区正文只有 24 像素，实际跳过 30 像素，且可靠地知道怎么回到上一处 | 自动回退一次，核对接缝后减小步长，用户无需再次操作，一路截到末尾。成图连续。 |
| 无法安全回退、回退失败或回退后下一步仍失配 | 暂停并保留已拼正确的部分。连点「自动翻页」没有新的滚轮。手动滚回能接的位置后，用户可选择继续自动滚动。 |
| 首段失败后明确重开 | 「从这里开始」使用已确认的新预览。已有拼接进度时该动作不会出现。 |
| 鼠标原来在正文或工具条 | 在正文时保持原位，在工具条时只对已经确认的目标定位一次。 |
| 中断时点击输出，或暂停时仍有抓屏在途 | 接回前保留预览。过期抓屏不能追加内容或触发下一次滚动。 |
